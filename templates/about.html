ℹ️ About Library Management System

Project documentation, technology stack, and quality compliance details.

📌 Overview & Objectives

The Library Management System is designed to streamline book indexing, real-time availability tracking, borrowing status toggles, and multi-criteria search filtering for personal and institutional libraries.

🎯 Quality Goal

Q10 – Quality Documentation & User Guidance: Standardizing system manuals, API clarity, interactive help, and inline comments.

🎓 Course Context

BBAT104 - Fundamentals of TQM (Total Quality Management).

🛠️ Technology Stack

  • Python 3.x
  • Flask 3.x
  • SQLite 3
  • HTML5 & Vanilla CSS3
  • Google Fonts (Plus Jakarta Sans)

🌟 Key Quality & UI Features

  • Full CRUD operations (Create, Read, Update, Delete) for book records.
  • Real-time search and multi-dropdown filtering (Category & Status).
  • One-click status toggling between Available and Borrowed.
  • Live metrics dashboard overview (Total, Available, Borrowed, Categories).
  • Responsive layout built with modern glassmorphic aesthetics.
  • Standardized documentation: Interactive README, User Manual, & Knowledge Base.
