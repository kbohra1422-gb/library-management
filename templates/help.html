How to Borrow Books

Browse the Catalog, ensure the title is "Available", then open the Circulation desk to issue the book. The system automatically calculates your 14-day due date.

⚡

ISBN Auto-Lookup

When adding books, enter an ISBN-10 or ISBN-13 code and click "Lookup". The Open Library API will automatically retrieve title, author, category, and cover image.

💻

In-Browser E-Reader

Books with attached PDF copies can be read directly in your browser with full-screen distraction-free mode.

💬 Frequently Asked Questions

What is the standard circulation loan period and overdue fine?

Books are issued for an automated standard period of 14 calendar days. If an item is returned after the due date, an overdue fine of ₹5.00 per day is dynamically calculated and billed upon book check-in.

How does the hold reservation queue work?

If a title you want is currently borrowed by another patron, you can place a hold via the Holds menu. Once returned, the status updates to "Book Returned (Ready!)", giving you reservation priority.

Can I run this application in desktop window mode without a browser?

Yes! Run python main.py or double-click run_desktop_app.bat. It opens a dedicated native desktop application window powered by Edge WebView2. You can also run the legacy CustomTkinter GUI via python main.py --tkinter.

How do I export collection inventory to Excel or CSV?

Navigate to the Catalog tab and click the Export CSV button in the top right. Any active search terms or category filters will be reflected in the exported CSV.
